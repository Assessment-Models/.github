# Assessment-Models/.github

Organization-level defaults for the **Assessment-Models** ecosystem.

- [`profile/README.md`](profile/README.md) — the organization landing page (what the org is, how it relates to OpenDEA, how to find and conform models)
- [`GOVERNANCE.md`](GOVERNANCE.md) — repository taxonomy, naming conventions, lifecycle conventions, legacy classification, repository standard policy (CR-AM-ORG-RES-000)
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — contribution expectations and the contract-handshake requirement
- [`SECURITY.md`](SECURITY.md) — security policy baseline
- [`workflows/`](workflows/) — baseline CI policy documentation; reusable workflow implementations land with `assessment-ci` (CR-AM-11 Phase 1) and `maturity-model-standard` (CR-AM-ORG-RES-000)
